# Majedah portfolio

A responsive, dependency-free portfolio website built with semantic HTML, CSS, and a small JavaScript enhancement for the mobile navigation and current-year footer. Open `index.html` directly in a browser or serve the project directory with any static web server.

The three portfolio entries are labeled concept studies, not client projects. Before publishing, replace the example contact address (`hello@example.com`) in `index.html` with Majedah’s preferred email address.
